# naʻau kombucha — brand concepts

A static site presenting three brand directions for naʻau kombucha (Nagoya), prepared by Ivycoast.

## Pages

| File | What it shows |
|---|---|
| `index.html` | Overview: what we heard, research findings, colour options, the three directions, decisions needed |
| `current.html` | Direction 0 — Shiro: naʻau's current script logo, white and minimal |
| `lenora.html` | Direction 1 — Ippon: Lenora, sumi and framed atelier (palette A, Sumi & Kinari) |
| `ogg.html` | Direction 2 — Ma: Ogg, airy and hand-made (palette D, Gofun & Ōdo) |
| `*-home.html`, `*-product.html` | Responsive home and product page mockups for each direction |
| `collab.html` | naʻau × Ivycoast: the KOM'BAR product, planned assets, website language, how it ties to each direction |

Each direction page covers colour and tone, packaging, print, social and website, in that direction's own visual language.

## Publish on GitHub Pages

1. Create a repository and upload the contents of this folder (keep `index.html` at the root).
2. In the repository: **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`.
3. The site appears at `https://<username>.github.io/<repository>/` after a minute or two.

No build step is needed. Fonts load from Google Fonts; everything else is in `assets/`.

## Before sharing publicly

- The Lenora and Ogg wordmarks are images made from unlicensed font settings, shown for discussion. License the fonts before any real use, or keep the page unlisted.
- Text in ［brackets］ is placeholder content for naʻau to fill in: flavours, prices, dates, address, ingredients.
- Handwriting in the Ogg direction is a stand-in font (Klee One) until kimy's handwriting is scanned.
- Product photography is shown as labelled placeholders.
